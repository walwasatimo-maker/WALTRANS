WalTrans v4
===========
Upload ALL these files to your GitHub repository (replace the old ones):
index.html, config.js, sw.js, nllb-worker.js, manifest.json,
icon-192.png, icon-512.png, icon-maskable-512.png, proxy-worker.js (optional)

KEEP YOUR OWN config.js if you already filled in your feedback email/WhatsApp
(otherwise open config.js and fill ONE line: feedbackEmail, feedbackWhatsapp
or feedbackFormUrl; optionally appUrl = your GitHub Pages link).

After uploading, open the app online once and refresh twice so v4 replaces
the old cached version.
